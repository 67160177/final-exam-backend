# คำตอบโจทย์ที่ 3.1 (ตัวอย่างเฉลย)

## Error ที่ Jest แสดง

```
expect(received).toEqual(expected)
- Expected  [1, 2, 3, 4, 5]
+ Received  [6, 7, 8, 9, 10]
```

เทสต์ขอหน้า 1 ขนาด 5 รายการ ควรได้เมนู id 1-5 แต่ได้ 6-10 คือได้ข้อมูลของหน้า 2 แทน
ส่วนเทสต์หน้า 5 ได้ array ว่าง เพราะข้ามไปไกลเกินจำนวนข้อมูลที่มี (22 รายการ)
ข้อมูลทุกหน้าเลื่อนไปหนึ่งหน้า ปัญหาจึงอยู่ที่การคำนวณจุดเริ่มต้น ไม่ใช่ที่ query หรือ filter

## สาเหตุ

ใน `routes/menu.js` คำนวณ `offset = page * limit` แต่ `page` เริ่มนับที่ 1
หน้า 1 จึงได้ `offset = 5` ทำให้ข้าม 5 แถวแรกไปเสมอ และไม่มีทางเห็นข้อมูลหน้าแรกเลย

## วิธีแก้

เปลี่ยนเป็น `offset = (page - 1) * limit` หน้า 1 จะได้ offset 0 และหน้า 5 จะได้ offset 20 (เหลือ id 21-22)
